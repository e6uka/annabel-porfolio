# Nursing Portfolio

A single-page portfolio website for a registered nurse and midwife. It shows clinical experience, education, skills, licensure and certifications, with a downloadable PDF resume.

## Stack

Plain HTML in one file. Tailwind CSS is loaded from its CDN and the Inter font from Google Fonts, so the page needs an internet connection to look right. There is no build step and no package manager.

## Getting started

Open `index.html` in a browser, or serve the folder with any static server.

## Files

- `index.html`: the portfolio page
- `Okoye_Annabel_Adanna_Resume.pdf`: the resume linked from the page
- `certificate.jpeg` and `headshot.jpeg`: images used on the page

## Deployment

The site is published with GitHub Pages at https://e6uka.github.io/annabel-porfolio/. It can be hosted on any static host.
